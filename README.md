## 📌 Project Overview
A detailed mobile device market analysis using Tableau to explore brand market share, pricing strategies, device specifications, and regional sales trends. The project delivers interactive dashboards for competitive landscape insights.

## 🗂️ Files
| File | Description |
|------|-------------|
| Assingment 1.twbx | Tableau packaged workbook with full dashboard |
| MobileMarket_4sheets.xlsx | Mobile market dataset (4 data sheets) |
| Report.pdf | Full analysis report |
| Report.docx | Editable report document |

## 🛠️ Tools & Technologies
- **Tableau** — Interactive market analysis dashboards
- **Excel** — Dataset management & preprocessing

## 📊 Key Analysis
- Brand market share analysis & competitive positioning
- Price segmentation (budget, mid-range, premium tiers)
- Device spec comparison: RAM, storage, battery, camera
- Regional sales distribution mapping
- Year-over-year sales trend analysis

## 💡 Key Insights
- Dominant brands and their pricing strategy correlations
- Mid-range segment identified as the highest volume opportunity
- Spec-to-price ratio analysis for competitive benchmarking
